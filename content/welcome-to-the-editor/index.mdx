## What works here

- Frontmatter edited as a form above, or as raw YAML
- Split-pane markdown with live preview
- Drag an image onto the editor and it lands in this document's folder
- `⌘K` inserts a component from your Astro projects

Components render as placeholder blocks in preview — Astro renders them for real at build time.

> Everything saves to `content/<slug>/index.mdx`.

| Shortcut | Action |
| --- | --- |
| `⌘S` | Save now |
| `⌘K` | Component palette |
| `⇧⌘P` | Toggle preview |
